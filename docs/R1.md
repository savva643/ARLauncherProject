# Свой R1 для шлема GlaskiOS

R1 здесь — это не процессор для рендера, а маленький сопроцессор датчиков, как у Apple.
Он держит общие часы, раз в 1 мс читает IMU, запускает камеры и ИК-подсветку в нужный момент
и ставит всем кадрам точные метки времени. Рендер, VIO и руки остаются на большой плате.

## Чип R1

**RP2350** (Raspberry Pi Pico 2 / WeAct RP2350B с AliExpress, несколько долларов).

- PIO даёт точные до микросекунды импульсы: синхронный запуск камер (FSIN), строб ИК-диодов, приём сигнала TE (vsync) экрана.
- SPI до IMU на 1–8 кГц, USB 1.1 Full Speed (для IMU и меток времени хватает с запасом).
- Pico SDK без RTOS, паять ничего не нужно.

Если нужно больше: STM32H723 (WeAct), там USB HS и FPU на 550 МГц. ESP32 под R1 не годится: у него джиттер Wi-Fi.

## Два варианта шлема

| | A. Всё в очках | B. Очки + коробочка без провода |
|---|---|---|
| На голове | Orange Pi 5 Pro / CM5 (RK3588S) + R1 + IMU + камеры + экран | Radxa Zero 3W (RK3566: декодер H.265, Wi-Fi 6, 1–2 Вт) + R1 + IMU + камеры + экран |
| В коробочке | — (только аккумулятор на затылке) | Orange Pi 6 Plus (CIX P1) + аккумулятор |
| Канал | — | Wi-Fi 6, 5 ГГц, напрямую без роутера; добавляет 5–15 мс с джиттером |
| Поворот головы | 8–14 мс | 8–14 мс (доворот по IMU делает плата в очках) |
| Passthrough | 15–25 мс | 15–25 мс, если фон собирать в очках: камера → GPU Zero 3W → экран, а из коробочки приходит только слой виртуальных объектов с альфой |
| Вес, нагрев | тяжелее, RK3588S греется на лбу, нужен вентилятор | очки лёгкие, 45 TOPS и тепло уходят на пояс |

Orange Pi 6 Plus на голову ставить не стоит: под нагрузкой он потребляет десятки ватт.
Его место — вариант B. Для варианта A лучше RK3588S.

**Рекомендация: вариант B.** Он же укладывается в протокол: коробочка играет роль ПК, а очки — роль iPhone.

## Прошивка R1 (по шагам)

1. **IMU**: ICM-42688-P по SPI, FIFO, 1 кГц, метка времени по прерыванию → пакет `0x22 IMU` ([PROTOCOL_V2.md](PROTOCOL_V2.md)).
2. **Часы**: R1 — главные часы шлема (мкс). Хост синхронизируется через USB пинг-понг, как сейчас iPhone с ПК.
3. **Камеры**: импульс FSIN одновременно на 2× OV9281, время середины экспозиции → в метаданные кадра `0x21 VIDEO`.
4. **Глаза**: строб ИК-диодов 850 нм только во время экспозиции камер глаз → пакет `0x25 EYE`.
5. **Экран**: вход TE/vsync → точное время показа для `0x26 DISPLAY` / `0x27 ACK` и предсказания позы.
6. **Звук** (по желанию): I2S MEMS INMP441 → `0x24 AUDIO`.
7. **Служебное**: температура, ШИМ вентилятора, напряжение аккумулятора.

На плате очков (Linux): новый источник `R1Source` в SensorStream. Он читает USB от R1 и склеивает с кадрами V4L2 по меткам времени.
Дальше всё уходит в тот же протокол v2, поэтому ПК (или коробочка) ничего не меняет.

## Порядок

1. Pico 2 + ICM-42688-P на проводах → IMU 1 кГц по USB в SensorStream, сравнить с гироскопом iPhone (100 Гц).
2. + TE экрана → точное предсказание.
3. + FSIN двух OV9281 → стерео VIO.
4. + ИК-строб → айтрекинг.
