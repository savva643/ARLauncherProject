# Свой шлем GlaskiOS: рендер на плате, R1, цены

Решение:
- рендер прямо на плате, всё на голове;
- питание постоянное, от сети по кабелю, без аккумулятора;
- корпус — уже имеющийся VR-бокс под телефон: экран ставится на место телефона.

Цены — снимки листингов на осень 2026, с доставкой в Россию (AliExpress, российские магазины, Авито).
Курс и наличие меняются: перед покупкой проверяйте.

> **Статус (ноябрь 2026):** сборка выбрана (раздел 0), основная плата пока дорогая — покупка отложена.
> Можно начать с дешёвого: Pico 2 + ICM-42688-P (R1) и экраны, проверяя их на ПК через DP.
> Перед покупкой платы — сверить цену Orange Pi 5 Plus и проверить DP по USB-C.

## 0. Выбранная сборка: 2 экрана 120 Гц + плата + R1

**Экраны:** 2× 2.9" Sharp LS029B3SX02 1440×1440, 120 Гц, Wisecoco, одна плата **DP→MIPI** на оба (режим Extend: ОС видит один экран 2880×1440).

- Плата с HDMI (Toshiba TC358870) не подходит: её предел — HDMI 1.4, 297 МГц. Это ≈ 2880×1440 при ~65 Гц.
- 2880×1440 при 120 Гц — это ≈ 525 МГц. Нужен DisplayPort 1.2/1.4 (4 линии, HBR2).

**Плата:** нужен настоящий выход DisplayPort.

| Плата | DP-выход | Вывод |
|---|---|---|
| Orange Pi 5 Pro | нет: второй HDMI сделан мостом DP→HDMI (LT8711UXD), DP наружу не выведен | **не подходит** для 120 Гц |
| **Orange Pi 5 Plus** (RK3588, Mali-G610) | USB-C DP 1.4a, до 4K60 (≈ 594 МГц, хватает на 2880×1440@120) | **берём** |
| Radxa Rock 5B / 5B+ (RK3588) | USB-C DP Alt Mode | запасной вариант |
| Orange Pi 6 Plus (CIX P1) | есть | дороже в 2 раза, горячий |

GPU у Orange Pi 5 Plus тот же, что у 5 Pro. Рендер: 90 Гц для обычной сцены и доворот кадра на 120 Гц
(простые сцены — честные 120 Гц).

**Риск:** DP Alt Mode по USB-C в основном ядре Linux для RK3588 ещё доделывается.
В образе Orange Pi на ядре Rockchip он должен работать, но **до покупки экранов проверить**:
подключить любой монитор через кабель USB-C→DP и выставить 2880×1440@120 (или близкий режим).

**R1:** RP2350 (Pico 2 / WeAct RP2350B) + ICM-42688-P.

| R1 (Pico 2) | Куда |
|---|---|
| USB | USB 2.0 порт Orange Pi (данные и питание 5 В) |
| GP2 SCK, GP3 MOSI, GP4 MISO, GP5 CS (SPI0) | ICM-42688-P: SCLK, SDI, SDO, CS |
| GP6 | ICM-42688-P INT1 (готовы данные / FIFO) |
| 3V3, GND | VDD/VDDIO, GND датчика |
| GP15 → GPIO Orange Pi (через общий GND) | метка 1 раз в секунду (PPS) для точной сшивки часов R1 и платы (`pps-gpio`) |
| GP10/GP11 (потом) | FSIN камер OV9281 |
| GP12 (потом) | строб ИК-диодов глаз (через транзистор) |

Время показа кадра берётся из DRM (метка vblank/page flip ядра), TE-вывод экрана не нужен:
панели работают в video mode через плату DP→MIPI.

**Питание:** блок 5 В / 5 А USB-C для Orange Pi 5 Plus (у неё отдельный USB-C для питания);
плата экранов — от USB-порта Orange Pi или от своего блока 5 В / 2 А, если её не хватит.

## 3. R1 и датчики

| Блок | Что | Цена |
|---|---|---|
| **R1** | RP2350 (Pico 2 / клоны с USB-C, AliExpress) | ~$2–5 (клоны); официальная Pico 2 ~$5–7 |
| IMU | ICM-42688-P на плате-модуле, SPI | модули на AliExpress — несколько долларов (проверить наличие); запас — BMI088 |
| Камеры (потом) | 2× OV9281 global shutter, IMX219 для фона | $30–40 за OV9281, $10–20 за IMX219; проверить драйвер под Orange Pi 5 Pro (у Orange Pi свои модули OV13850/OV13855) |

R1 подключается к плате по USB. Он держит часы шлема, читает IMU на 1 кГц, запускает камеры (FSIN),
стробирует ИК для глаз и ловит vsync экрана (TE).

## 4. Питание (постоянное)

- Блок 5 В / 5 А USB-C (рекомендованный для Orange Pi 5 Pro) — ~1–1.5 тыс. ₽.
- Кабель USB-C 2–3 м, мягкий, закрепить на затылке, чтобы не дёргал шлем.
- Плата экрана питается от USB-порта Orange Pi (около 0.5–1 А).

## 6. Прошивка R1 (по шагам)

1. **IMU**: ICM-42688-P по SPI, FIFO, 1 кГц, метка времени → пакет `0x22 IMU` ([PROTOCOL_V2.md](PROTOCOL_V2.md)).
2. **Часы**: R1 — главные часы шлема (мкс), плата синхронизируется по USB пинг-понгом.
3. **Экран**: TE/vsync → время показа для предсказания позы.
4. **Камеры**: FSIN одновременно на 2× OV9281, время середины экспозиции → `0x21 VIDEO`.
5. **Глаза**: строб ИК 850 нм только во время экспозиции → `0x25 EYE`.
6. Потом: I2S-микрофон (`0x24 AUDIO`), температура, вентилятор.

На плате (Linux): источник `R1Source` в SensorStream читает USB от R1 и склеивает с кадрами V4L2 по меткам времени.
ARLauncher (Vulkan) работает прямо на Orange Pi: PanVK, Mali-G610.
