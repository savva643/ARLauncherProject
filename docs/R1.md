# Свой R1 и шлем «всё на голове» (дешёвый прототип)

Решение: всё железо на голове, без коробочки. Первая версия — тонкий клиент:
рендер, VIO и руки считает ПК, как сейчас с iPhone. Шлем сам доворачивает кадр по IMU
и сам показывает фон с камеры. Автономный режим (рендер на плате) — потом, тот же протокол.

## R1 — сопроцессор датчиков

**RP2350** (Raspberry Pi Pico 2 / WeAct RP2350B с AliExpress, несколько долларов).
Рендером он не занимается. Он держит часы шлема, читает IMU на 1 кГц,
запускает камеры, стробирует ИК-подсветку и ловит vsync экрана.

- PIO даёт импульсы с точностью до микросекунды: FSIN камер, ИК-строб, вход TE экрана.
- SPI до IMU на 1–8 кГц, USB Full Speed (для IMU и меток времени с запасом).
- Pico SDK, без пайки.

Запасной вариант: STM32H723 (WeAct). ESP32 не подходит: у него джиттер Wi-Fi.

**Для прототипа: плата на RK3576.**
Она дешевле, холоднее и легче, чем RK3588S. Для тонкого клиента этого достаточно:
декод, доворот, фон с камеры, IMU через R1. Если позже понадобится автономный рендер —
меняем плату на Orange Pi 5 Pro (тот же Rockchip MPP, тот же код).

Если нужно совсем дёшево, а экран один по HDMI — Radxa Zero 3W. Но с запасом по GPU у неё плохо.

## Чтобы на голове было не тяжело

- Аккумулятор (power bank USB-C PD) — на затылок, как противовес. Спереди только экран, линзы и камеры.
- Плата — сверху или сзади, не на лбу.
- Шлем на 3–5 Вт: power bank на 10 000 мА·ч хватает примерно на 6–8 ч (оценка).

## Связь с ПК: свой протокол

| | Сейчас (TCP, кадр целиком) | Свой протокол |
|---|---|---|
| Кодирование на ПК | 8–13 мс | по полосам (slices), 2–4 мс до первой отправки |
| Эфир Wi-Fi | 5–15 мс, провалы 50+ мс | UDP без повторов, FEC, ~1 мс на кадр |
| Декод на шлеме | 3–5 мс | по полосам, 2–4 мс |
| **Канал целиком** | **15–35 мс** | **≈ 5–10 мс** (по USB/Ethernet — ещё меньше) |

Поворот головы (5–10 мс) и фон (10–20 мс) считаются на шлеме, от канала не зависят.
Канал заметен только у рук и анимации.

Что делает протокол: UDP, опоздавший кадр выбрасывается (шлем доворачивает старый),
отправка полосами, FEC 10–20 %, Wi-Fi без роутера на чистом канале 5/6 ГГц, энергосбережение Wi-Fi выключено,
битрейт подстраивается по ACK.

## Прошивка R1 (по шагам)

1. **IMU**: ICM-42688-P по SPI, FIFO, 1 кГц, метка времени → пакет `0x22 IMU` ([PROTOCOL_V2.md](PROTOCOL_V2.md)).
2. **Часы**: R1 — главные часы шлема (мкс), плата синхронизируется по USB пинг-понгом.
3. **Камеры**: FSIN одновременно на 2× OV9281, время середины экспозиции → в метаданные `0x21 VIDEO`.
4. **Глаза**: строб ИК 850 нм только во время экспозиции → `0x25 EYE`.
5. **Экран**: TE/vsync → время показа для `0x26 DISPLAY` / `0x27 ACK`.
6. Потом: I2S-микрофон (`0x24 AUDIO`), температура, вентилятор, батарея.

На плате (Linux): источник `R1Source` в SensorStream читает USB от R1 и склеивает с кадрами V4L2 по меткам времени.

## Порядок и бюджет прототипа

1. Плата RK3576 + 5.5–6" LCD 1440×2560 (набор HDMI→MIPI) + VR-корпус с линзами + Pico 2 + ICM-42688-P + power bank.
   Картинка с ПК, доворот по IMU 1 кГц. **≈ $150–250** (оценка).
2. + IMX219 → фон прямо на шлеме.
3. + 2× OV9281 с FSIN → 6DoF без iPhone.
4. + ИК-камеры глаз со стробом → айтрекинг.
