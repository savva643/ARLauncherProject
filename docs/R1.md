# Свой шлем GlaskiOS: рендер на плате, R1, цены

Решение:
- рендер прямо на плате, всё на голове;
- питание постоянное, от сети по кабелю, без аккумулятора;
- корпус — уже имеющийся VR-бокс под телефон: экран ставится на место телефона.

Цены — снимки листингов на осень 2026, с доставкой в Россию (AliExpress, российские магазины, Авито).
Курс и наличие меняются: перед покупкой проверяйте.

## 3. R1 и датчики

| Блок | Что | Цена |
|---|---|---|
| **R1** | RP2350 (Pico 2 / клоны с USB-C, AliExpress) | ~$2–5 (клоны); официальная Pico 2 ~$5–7 |
| IMU | ICM-42688-P на плате-модуле, SPI | модули на AliExpress — несколько долларов (проверить наличие); запас — BMI088 |
| Камеры (потом) | 2× OV9281 global shutter, IMX219 для фона | $30–40 за OV9281, $10–20 за IMX219; проверить драйвер под Orange Pi 5 Pro (у Orange Pi свои модули OV13850/OV13855) |

R1 подключается к плате по USB. Он держит часы шлема, читает IMU на 1 кГц, запускает камеры (FSIN),
стробирует ИК для глаз и ловит vsync экрана (TE).

## 4. Питание (постоянное)

- Блок 5 В / 5 А USB-C (рекомендованный для Orange Pi 5 Pro) — ~1–1.5 тыс. ₽.
- Кабель USB-C 2–3 м, мягкий, закрепить на затылке, чтобы не дёргал шлем.
- Плата экрана питается от USB-порта Orange Pi (около 0.5–1 А).

## 6. Прошивка R1 (по шагам)

1. **IMU**: ICM-42688-P по SPI, FIFO, 1 кГц, метка времени → пакет `0x22 IMU` ([PROTOCOL_V2.md](PROTOCOL_V2.md)).
2. **Часы**: R1 — главные часы шлема (мкс), плата синхронизируется по USB пинг-понгом.
3. **Экран**: TE/vsync → время показа для предсказания позы.
4. **Камеры**: FSIN одновременно на 2× OV9281, время середины экспозиции → `0x21 VIDEO`.
5. **Глаза**: строб ИК 850 нм только во время экспозиции → `0x25 EYE`.
6. Потом: I2S-микрофон (`0x24 AUDIO`), температура, вентилятор.

На плате (Linux): источник `R1Source` в SensorStream читает USB от R1 и склеивает с кадрами V4L2 по меткам времени.
ARLauncher (Vulkan) работает прямо на Orange Pi: PanVK, Mali-G610.
