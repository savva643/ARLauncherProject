# GlaskiOS / LensEngine: что работает

Состояние ветки `main` (Vulkan-лаунчер + ARStreamer `noarkit`). Сравнение с Apple Vision Pro (visionOS + ARKit).

- ✅ работает и проверено (тесты, симулятор комнаты, слой валидации Vulkan без ошибок);
- 🟡 частично / ограничено железом iPhone;
- ❌ нет.

Модули сделаны так, чтобы iPhone можно было заменить «настоящими» модулями шлема: камеры, LiDAR,
ИК-камеры глаз и микрофон приходят по одному протоколу v2 ([PROTOCOL_V2.md](PROTOCOL_V2.md)).

## Трекинг и понимание пространства

| Функция | Vision Pro / ARKit | GlaskiOS / LensEngine | Статус |
|---|---|---|---|
| Поворот головы 3DoF | ✅ | IMU 100 Гц, Mahony + bias, предсказание на момент показа; тест 0.75° | ✅ |
| Позиция 6DoF | ✅ WorldTracking | LiDAR-ICP + IMU (`LidarOdometry`); тест: 0.9 см средняя, 1.8 см макс. | ✅ |
| Без дрейфа | ✅ | Рысканье гироскопа по LiDAR (16° → 0.1°), знакомое место сбрасывает ошибку | ✅ |
| Карта и якоря между запусками | ✅ WorldAnchor | `world.map`: ключевые кадры LiDAR + меш + якоря; узнавание комнаты за 0.7 с, якорь ±1 см (`test_world_map`) | ✅ |
| Меш комнаты (SceneReconstruction) | ✅ с классами | TSDF + surface nets, классы пол/стена/потолок/стол/прочее; ошибка 1.2 мм (`test_scene_reconstruction`) | ✅ |
| Плоскости (PlaneDetection) | ✅ | Пол, столы, потолок, стены — центр, нормаль, размеры (пол 5.01×5.99 м при 5×6) | ✅ |
| Метки / изображения | ✅ любые картинки | Метки ArUco 4×4 (7 мм, 2°); произвольные картинки — нет | 🟡 |
| Отслеживание объектов по 3D-модели | ✅ | — | ❌ |
| Руки (HandTracking) | ✅ 27 суставов | MediaPipe 21 сустав (`HandTrackingProvider`), 3D по LiDAR, щипок/кулак/луч; на фото — обе руки, включая перевёрнутую | ✅ |
| Взгляд (eye tracking) | ✅ | `EyeTracker`: зрачок на ИК-кадре, калибровка 9 точек; тест 0.46° средняя. Нужны ИК-камеры глаз (пакет EYE); в iPhone их нет | ✅ модуль |
| Крепление устройства | — | Авто 0/90/180/270° или вручную (M) | ✅ |

## Тесты

| Тест | Что проверяет |
|---|---|
| `test_head_tracker`, `test_tracking_session` | ориентация, bias, предсказание, крепление 0/90/180/270 |
| `test_lidar_odometry` | позиция и рысканье по LiDAR, пол |
| `test_world_map` | сохранение карты, узнавание комнаты из другой точки, якорь на месте |
| `test_scene_reconstruction` | точность меша, классы, плоскости, сохранение объёма |
| `test_hand_tracking` | руки на реальном фото (обе, включая перевёрнутую) |
| `test_eye_tracker` | зрачок, калибровка, ошибка взгляда |
| `test_environment_probe`, `test_marker_tracker`, `test_audio` | свет, метки, HRTF/окклюзия звука |
