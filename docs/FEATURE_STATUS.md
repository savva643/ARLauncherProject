# GlaskiOS / LensEngine: что работает

Состояние на ветке `main` (Vulkan-лаунчер + ARStreamer `noarkit`).

- ✅ работает и проверено (тесты, симулятор, слой валидации Vulkan);
- 🟡 работает частично или только как код без подключения;
- ❌ нет.

## Данные с iPhone

| Что | Статус | Подробности |
|---|---|---|
| Видео камеры | ✅ | H.264 / HEVC аппаратно, 720p–4K, до 60 к/с; интринсики и время экспозиции у каждого кадра |
| Ориентация потока | ✅ | Всегда родная ориентация сенсора, без зеркала. Поворот телефона и UI поток не меняет |
| Цвет | ✅ | 420f full range, BT.709 передаются флагами в пакете; на ПК YUV→RGB в шейдере (full/limited, 709/601) |
| IMU | ✅ | Сырые гироскоп и акселерометр 100 Гц, магнитометр 50 Гц, аппаратные метки времени на общих часах с камерой |
| LiDAR | ✅ | 256×192 float16, метры, выровнена с кадром камеры, интринсики; превью на телефоне и наложение на ПК (клавиша **L**) |
| Превью на телефоне | ✅ | RGB / LiDAR / оба; поворачивается вместе с интерфейсом (портрет, ландшафт, перевёрнутый) |
| Звук с телефона | ❌ | Микрофон не захватывается и не передаётся |

## Трекинг (LensEngine)

| Что | Статус | Подробности |
|---|---|---|
| Ориентация головы 3DoF | ✅ | Mahony + оценка bias гироскопа; тест: средняя ошибка 0.6° |
| Предсказание и late latching | ✅ | Поза предсказывается на момент показа кадра |
| Репроекция видео | ✅ | Мир неподвижен при задержке видео 40–80 мс; тест осей: 0.04° |
| Крепление телефона в шлеме | ✅ | 0°/180° авто по гравитации; если телефон перевернули, переключается само за ~1 с |
| Позиция 6DoF | 🟡 | OpenVINS (VIO) собирается и запускается; на живых данных iPhone ещё не проверен. Без него 3DoF + модель шеи |
| Позиция по LiDAR (DLIO) | 🟡 | `DLIOWrapper` — заглушка; облако точек грубое (шаг 32 px, интринсики не используются) |
| Руки | 🟡 | `HandTracker` есть, но RGB-кадры в него не идут, а модели ONNX лежат по пути с другой машины |
| Плоскости, меш, понимание сцены | 🟡 | `PlaneDetector`, `MeshGenerator`, `SceneUnderstanding` в рендер не подключены |
| Метки / теги (ArUco, AprilTag) | ❌ | Нет; в OpenVINS ArUco выключен |

## Рендер (Vulkan)

| Что | Статус | Подробности |
|---|---|---|
| Passthrough-видео | ✅ | NV12 на GPU, репроекция, мягкий край поля зрения, затухание при обрыве потока |
| Частота | ✅ | MAILBOX, 2 кадра в полёте, рендер с частотой дисплея (120 Гц и выше, если дисплей умеет) |
| Стерео side-by-side | ✅ | `ARL_STEREO=1`, IPD; камера одна, поэтому видео моно |
| 3D-объекты | ✅ | Меши с простым освещением: фиксированное направление света, half-Lambert |
| 3D-окна UI и HUD | ✅ | HUD показывает камеру, трекинг, IMU, крепление, битрейт, LiDAR |
| Тени | ❌ | `ShadowRenderer` (LensEngine) есть, но Vulkan-рендер его не использует |
| Освещение по камере | ❌ | `SHLightEstimator` есть, но не подключён: объекты не подстраиваются под свет комнаты |
| Отражения, PBR, карта окружения | ❌ | Нет |
| Окклюзия (реальные предметы закрывают виртуальные) | ❌ | Нет; LiDAR для этого уже приходит на GPU |
| Коррекция дисторсии линз шлема | ❌ | Нужны параметры линз |
| OpenGL | LEGACY | Не трогается, по умолчанию выключен |

## Логичный порядок дальше

1. **Окклюзия по LiDAR.** Глубина уже лежит в текстуре на GPU, нужен только тест глубины в шейдере. Это даёт самый заметный эффект «объект стоит в комнате».
2. **Тени на пол.** Пол брать из LiDAR или плоскостей, плюс shadow map в Vulkan.
3. **Освещение по камере.** Подать кадры в `SHLightEstimator`, отправить SH-коэффициенты в `mesh.frag`. Отсюда же — простые отражения из карты окружения по видео.
4. **Пространственный звук.** OpenAL Soft (HRTF) или Steam Audio, поза слушателя из `TrackingSession`.
5. **Метки.** AprilTag или ArUco через OpenCV `aruco` на кадре, который уже приходит в VIO.
