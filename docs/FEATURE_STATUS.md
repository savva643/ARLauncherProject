# GlaskiOS / LensEngine: что работает

Состояние на ветке `main` (Vulkan-лаунчер + ARStreamer `noarkit`).

- ✅ работает и проверено (тесты, симулятор комнаты, слой валидации Vulkan без ошибок);
- 🟡 работает частично или не проверено на живом iPhone;
- ❌ нет.

## Данные с iPhone

| Что | Статус | Подробности |
|---|---|---|
| Видео камеры | ✅ | H.264 / HEVC аппаратно, 720p–4K, до 60 к/с; интринсики и время экспозиции у каждого кадра |
| Ориентация потока | ✅ | Всегда родная ориентация сенсора, без зеркала. Поворот телефона и UI поток не меняет |
| Экран телефона при подключении | ✅ | Замирает в текущей ориентации (не переворачивается в шлеме), после отключения — как было |
| Цвет | ✅ | 420f full range, BT.709 передаются флагами в пакете |
| IMU | ✅ | Сырые гироскоп и акселерометр 100 Гц, магнитометр 50 Гц, общие часы с камерой |
| LiDAR | ✅ | 256×192 float16, метры, выровнена с кадром камеры |
| Звук с телефона (микрофон) | ❌ | Не передаётся |

## Трекинг (LensEngine)

| Что | Статус | Подробности |
|---|---|---|
| Ориентация головы 3DoF | ✅ | Mahony + bias гироскопа; тест: средняя ошибка 0.75° |
| Калибровка гироскопа | ✅ | Автоматически, когда голова неподвижна (по разбросу гироскопа — медленный поворот головы больше не принимается за bias) |
| Позиция 6DoF по LiDAR | ✅ | ICP карты глубины + IMU, карта ключевых кадров комнаты. Тест (40 с хождения по комнате): средняя ошибка 0.9 см, макс. 1.8 см |
| Без дрейфа | ✅ | Дрейф гироскопа по рысканью убирается LiDAR (тест: 16° дрейфа → 0.1°). Вернулся в знакомое место — накопленная ошибка позиции сбрасывается |
| Пол | ✅ | Находится по LiDAR (тест: ошибка 4 см) |
| Предсказание и late latching | ✅ | Поза на момент показа кадра; позиция между картами LiDAR — по акселерометру (100 Гц) |
| Репроекция видео | ✅ | Мир неподвижен при задержке видео 40–80 мс |
| Крепление телефона в шлеме | ✅ | Авто 0/90/180/270° по гравитации или вручную (клавиша **M**, `ARL_MOUNT`) |
| VIO (OpenVINS) | 🟡 | Используется только если нет LiDAR; на живом iPhone не проверен |
| Метки ArUco | ✅ | DICT_4X4_50, якорь в мире (тест: 7 мм, 2°); кубик стоит на метке и остаётся на месте вне кадра |
| Руки | 🟡 | `HandTracker` есть, кадры не подключены, модели ONNX лежат по пути с другой машины |
| Плоскости, кроме пола; меш комнаты | 🟡 | Пол — да; столы/стены как плоскости и меш — нет |

## Рендер (Vulkan)

| Что | Статус | Подробности |
|---|---|---|
| Passthrough-видео | ✅ | NV12 на GPU, репроекция, мягкий край, затухание при обрыве |
| Окклюзия | ✅ | Реальные предметы (LiDAR) закрывают виртуальные: ушёл за стену — объект пропал; предмет перед объектом — закрывает его. Мягкий край. Клавиша **K** |
| Освещение по комнате | ✅ | Карта окружения собирается из видео по мере осмотра; диффузный свет — сферические гармоники. Клавиша **E** |
| Отражения | ✅ | Металл/глянец отражают собранную карту комнаты (хром, золото в демо-сцене) |
| Тени | ✅ | Объекты отбрасывают тень на найденный пол от самого яркого источника (лампа/окно); тень тоже прячется за реальными предметами. Клавиша **H** |
| Объекты на полу | ✅ | Демо: шар и куб ставятся на реальный пол, когда он найден |
| Стерео side-by-side | ✅ | `ARL_STEREO=1`, IPD; камера одна, поэтому видео моно |
| HUD | ✅ | Камера, режим трекинга, позиция, карта LiDAR, пол, IMU, крепление, битрейт, метки |
| Коррекция дисторсии линз шлема | ❌ | Нужны параметры линз |
| OpenGL | LEGACY | Не трогается, по умолчанию выключен |

## ПК: GlaskiOS Control

`python3 tools/glaski_control.py` — окно со всеми переключателями: сборка, «Собрать и запустить», симулятор iPhone, сборка OpenVINS, журнал. Без окна: `--build`, `--run`.
